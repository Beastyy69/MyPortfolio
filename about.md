# About this website

The personal portfolio of **Harshit Shaw** — AIML Developer, Backend Engineer and Builder.

It is a single‑page React site with two complete worlds:

- **AI/ML Mode** (always the default): a calm, editorial engineering portfolio in deep ink, warm ivory, muted sage and brass.
- **Game Mode — *Code Frontier***: an original adventure world in espresso, burgundy, parchment, mustard, olive and dusty red.

Visitors switch worlds with the toggle in the navbar. A full‑screen tile transition
carries them across, and they stay on the same section at the same scroll position.

## Page order

1. **Opening film** — scattered identities connect and become one bold **HS** signature
2. **Hero** — name, role, tagline, links (Game Mode adds the World Preview Strip)
3. **About** — story, roles and stats; the hero photo morphs into the *About My Work* panel
4. **Skills** — neural "My Skills" universe / Code Frontier Atlas
5. **Projects** — editorial case studies / Mission Select Gallery
6. **Certificates** — credential ledger / trophy badges
7. **Journey** — sticky timeline / career campaign map
8. **Core Run** — Game Mode only: a 30‑round original platformer
9. **Contact** — contact tiles and a message form

## Design principles

- No neon, glow, cyberpunk effects or RGB gradients in either world.
- Original illustrations only — no assets, characters or logos from existing games.
- Depth from shadow, grain and layering; motion that is calm and purposeful.
- Respects reduced‑motion preferences and works with keyboard alone.
